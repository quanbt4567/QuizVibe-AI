- (decision) Target audience: small e-commerce shop owners & social media marketing managers. Players motivated by rewards (voucher/gift), competition (top 10), and entertainment.
- (decision) Reward mechanism: Direction A (Discount Voucher) as primary with Direction B (Viral Leaderboard/Share) as supporting. Immediate copyable voucher reward upon valid VN phone entry. Direction C excluded from MVP.
- (decision) AI Generation: Preset templates + custom topic + difficulty level. Mandatory admin review/edit step before publishing. Strict JSON schema validation (5 questions x 4 options x 1 correct). Controlled repair/retry fallback. Transparent AI status labeling.
- (decision) Gameplay mechanics finalized: Score = 100 + (10 * remaining whole seconds) per correct answer; 0 for wrong/timeout (max 2,000 pts). Auto-advance on 00:00 with 1s feedback. Top 10 leaderboard strictly gated behind valid lead submission. Tie-break by lowest total answering time.
- (decision) Social sharing: Dynamic snippet + Web Share API with Clipboard fallback. Admin operations: View, search, delete (single/all with confirm), UTF-8 BOM CSV export. Stack: React 19 + TypeScript + Vite + Tailwind CSS + Vercel Serverless proxy for AI API security. LocalStorage persistence strictly preserved without backend/auth.
